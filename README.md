🏰 Vibe Castle — My Experience

Vibe Castle was a vibe coding event conducted in our college where we had to use AI to build and improve different applications through multiple rounds.

Round 1 — UI Recreation 🎨

In the first round, we were shown a UI and had to understand the design and recreate it using AI.

We had to figure out the layout, components, colors, spacing, animations and functionality just by looking at the given design and then explain it properly to the AI.

It was basically about how well we could visualize a design and convert that idea into a working website using AI.

Round 2 — Music Player 🎵

In the second round, we had to build a music player using HTML, CSS and JavaScript.

We started with the basic player and then added features like:

Play/Pause
Previous/Next
Actual music playback
Playlist with 5 songs
Progress bar
Seeking
Volume control
Shuffle
Repeat
Automatic next song
Active song highlighting

This round was more about making sure the website wasn't just looking good but was actually functional.

Round 3 — Employee Management App 👨‍💼

For the third round, we were given a GitHub repository containing a basic CRUD/employee management application.

Our task was to take that existing application and enhance the UI and UX.

Instead of changing the core idea, we had to make it feel much more modern by improving the layout, styling, interactions, animations and overall experience.

One thing I wanted to focus on was making my version different from the typical AI-generated redesigns. Since everyone started with the same repository and could use AI, simply asking AI to "make it beautiful" could result in very similar websites.

So I tried to give more specific directions and focus on the small details — especially the UI structure, micro-interactions, animations and overall feel.

What I learned

The biggest thing I learned from Vibe Castle is that vibe coding isn't just about asking AI to write code.

You still need to know what you want, explain it properly, test it, find what feels wrong and keep refining it.

For me, the event was a really good experience because each round was different — first recreating a design, then building functionality, and finally taking an existing project and making it feel like a completely better product.
